# Hierarchical Path Planning and Decentralized Control Architecture

The system employs a three-tiered hierarchical control architecture designed to ensure robust multi-agent coordination, efficient area coverage, and collision-free navigation. This architecture decomposes the complex swarm mission into three distinct layers: Global Task Allocation, Local Trajectory Generation, and Reactive Control.

## 1. Global Task Allocation: Market-Based Consensus
At the highest level of abstraction, the system utilizes a **Market-Based Approach** (MBA) for decentralized task allocation. This mechanism treats the search space $\mathcal{S}$ as a set of discrete grid sections $\{s_1, s_2, ..., s_m\}$, which function as commodities in a virtual economy.

*   **Mechanism**: The swarm implements a greedy decentralized auction where each drone $d_i$ bids on available sections based on a cost function $J(d_i, s_j)$ proportional to the Euclidean distance $||\mathbf{p}_{d_i} - \mathbf{p}_{s_j}||$. 
*   **Dynamic Replanning**: Assignments are not static; the system supports dynamic reallocation (`dynamic_update`). If an agent fails (e.g., battery depletion or fault injection), its owned resources (sections) are released back to the market, allowing other agents to bid on them, ensuring system-wide fault tolerance.
*   **Implementation**: Encapsulated within the `MarketSystem` class (`market.py`), managing the virtual currency ("points") and state transitions of search sectors.

## 2. Local Path Planning: Coverage Trajectory Generation
Upon securing a task assignment (grid section), the agent transitions to the local planning layer to generate a feasible search path.

*   **Strategy**: The system employs a **Boustrophedon (Lawnmower) Decomposition** technique. This deterministic coverage algorithm guarantees complete sensor coverage of the assigned rectangular region by generating a sequence of parallel waypoints.
*   **Path Geometry**: The path $\mathcal{P}_i = \{w_1, w_2, ..., w_k\}$ is generated relative to the section's centroid, with sweep spacing determined by the sensor's effective field of view to minimize overlap while ensuring zero coverage gaps.
*   **Implementation**: computed in `main.py` via `generate_lawnmower_points()`, producing a sequence of 3D coordinates $(x, y, z)$ that constitute the reference trajectory.

## 3. Reactive Control Layer: Hybrid Navigation
The lowest layer executes the generated trajectory while maintaining safety through a hybrid control scheme that combines global path following with local reactive collision avoidance.

*   **Artificial Potential Fields (APF)**: To navigate dynamic environments, the system superimposes an attractive force $\mathbf{F}_{att}$ (towards the current waypoint) with repulsive forces $\mathbf{F}_{rep}$ generated by obstacles, boundaries, and other agents.
    *   **Agent-Agent Repulsion**: Modeled as a repulsive potential $U_{rep} \propto \frac{1}{||\mathbf{p}_i - \mathbf{p}_j||^2}$, ensuring inter-agent collision avoidance (`avoidance_from_drones`).
    *   **Boundary Constraints**: Soft-constraint repulsive fields keep agents within the operational theater (`avoidance_from_borders`).
*   **Low-Level Control**: The resultant velocity vector $\mathbf{v}_{cmd}$ is fed into a **PID Controller** (Proportional-Integral-Derivative), specifically the `DSLPIDControl` module, which computes the necessary rotor mixing and motor RPMs to track the desired state vector.
*   **Implementation**: The integration occurs in the main simulation loop (`step()`), where the `DSLPIDControl` regulates the drone's dynamics to realize the high-level intent modulated by the APF safety layer.

## Summary
The system achieves emergent swarm intelligence through this layered coupling:
1.  **Macro-Level**: Efficient distribution of work via the Market.
2.  **Meso-Level**: Systematic area exploitation via Boustrophedon paths.
3.  **Micro-Level**: Safe, robust execution via Potential Fields and PID control.
